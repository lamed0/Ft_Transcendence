🚀 Getting Started

To run the project locally, please follow the instructions below.

1️⃣ Navigate to the docker-compose directory 

```bash
cd my-game
```

2️⃣ Simply run: 

```bash
docker compose up --build
```

note : please check if you have docker installed if not, install it first.
