# 🏓 ft_transcendence (Ping Pong Platform)

A real-time multiplayer Ping Pong game built by students, for students. We are mixing a classic arcade game with modern web security and blockchain tech.

🚧 **Status:** Work in Progress

## 🔥 What is this?
This isn't just a game. It's a full-stack platform where you can play matches, track your stats, and see your history recorded permanently.

**Key Features:**
* **Real-time Gameplay:** Fast and responsive ping pong matches.
* **Blockchain Scoring:** We use **Solidity/Avalanche** to store match scores. Once you win, it's on the chain forever. No cheating.
* **Security First:** 2FA, WAF, and Vault integration to keep user data safe.
* **Privacy:** Fully GDPR compliant (we respect your data).
* **Dashboard:** specialized dashboards to track your progress.

## 🛠️ The Tech Stack
We are building this with the tools we love:
* **Backend:** Node.js (NestJS) & TypeScript
* **Frontend:** HTML / Tailwind CSS
* **Database:** SQLite / PostgreSQL
* **DevOps:** Docker & Nginx
* **Blockchain:** Solidity (Avalanche)
